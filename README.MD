# Resumo do Projeto

Neste Projeto será reconstruído a ideia do projeto de calculadora em C para que assim minha cabeça possa se aquecer novamente com o projeto e de não deixar ela abandonada, então aproveitar esse meu hype quanto a esse projeto

Sobre o que pretendo fazer com este projeto é de fazer uma calculadora geral de vários tipos de cálculos como os normais que uma calculadora faz e até calcular funções matemáticas e físicas complexas

Então em resumo pretendo fazer Calculadora normal, exatamente igual a lógica funcional da que temos em nosso computador, calculadora de binários, conversor de moeda, funções matemáticas, funções físicas e calculos financeiros como os de juros compostos.

E no caso este projeto já se encontra em meu github sendo apenas trocar lá a pasta do arquivo para poder estar atualizando o projeto.

Com isso foi estimular um prazo para que eu termine este caso dentro de um prazo de 2 meses para ficar pronto
